# 高情商聊天回复助手启动方式

## 适用场景

这份说明只针对本地桌面版。

如果你已经创建并激活了自己的虚拟环境或 conda 环境，可以直接在本地运行，不需要额外的 Web 服务，也不需要额外启动器。

## 默认启动方式

先进入项目根目录：

```powershell
cd 路径\to\chat-agent
```

然后直接运行：

```powershell
python -m apps.desktop.main
```

如果你还想沿用旧入口，也可以执行：

```powershell
python chat_assistant.py
```

`chat_assistant.py` 现在只是兼容入口，最终也会转发到 `apps.desktop.main`。

## 本地环境准备

### 1. 安装依赖

你当前如果走的是 OCR API 路径，直接安装：

```powershell
python -m pip install -r requirements.txt
```

### 2. 创建配置文件

```powershell
Copy-Item .env.example .env
```

至少填写：

```env
BAIDU_ACCESS_TOKEN="你的_ACCESS_TOKEN"
ERNIE_MODEL="ernie-5.0-thinking-preview"
OCR_BACKEND="api"
PADDLEOCR_API_URL="https://你的-aistudio-app/layout-parsing"
PADDLEOCR_TOKEN="你的_PADDLEOCR_TOKEN"
REQUEST_TIMEOUT="60"
HOTKEY="ctrl+alt+q"
HOTKEY_ENABLED="false"
```

## 使用方式

程序启动后：

1. 桌面边缘会出现贴边浮窗。
2. 点击 `截图` 开始采集聊天内容。
3. 等待 OCR API 和模型返回结果。
4. 在结果面板里复制、重写或继续处理文档。

## 说明

### 本地虚拟环境可以直接运行

可以。

之前报错不是环境问题，而是代码里 `AppController` 缺少方法，属于程序本身的错误，不是因为你用了本地环境。

### 如果以后切换到本地 OCR

当前默认不是本地 OCR。

只有当你把 `.env` 改成：

```env
OCR_BACKEND="local"
```

才需要额外安装：

```powershell
python -m pip install paddlepaddle paddleocr Pillow numpy
```

## 常见问题

### 启动时报缺少 `PyQt5`

```powershell
python -m pip install -r requirements.txt
```

### 截图后没有结果

优先检查：

- `.env` 中的 `BAIDU_ACCESS_TOKEN`
- `.env` 中的 `PADDLEOCR_API_URL`
- `.env` 中的 `PADDLEOCR_TOKEN`
- 当前网络是否能访问 OCR API 和文心接口

### 热键没有反应

当前默认主入口是贴边浮窗，不依赖热键。

如果你主动启用了热键，再排查：

- `HOTKEY_ENABLED` 是否为 `true`
- `HOTKEY` 是否与其他软件冲突
